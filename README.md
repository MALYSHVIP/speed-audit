# TokerVPN Speed Audit

Небольшой GitHub-ready набор для установки Ookla Speedtest и понятной проверки сервера на русском языке.

После первого запуска установщик:

- ставит только нужные пакеты;
- устанавливает `speedtest`, если его еще нет;
- раскладывает локальную команду `tokervpn-speed-audit`;
- сразу показывает итоговый отчет по серверу.

При повторном запуске установщик ничего не переустанавливает и сразу переходит к проверке, если `speedtest`, `jq`, `curl` и локальный скрипт уже на месте.

## Что показывает отчет

- загрузку процессора и краткую оценку;
- сколько занято оперативной памяти и сколько доступно;
- сколько занято и сколько свободно на диске;
- оценку служебного мусора: кеш `apt`, временные файлы и журналы;
- ping, jitter, потери пакетов;
- скорость загрузки и отдачи;
- итоговую рекомендацию простыми русскими словами.

## Структура

- `install.sh` — самодостаточный установщик для локального запуска и для `curl | bash`;
- `bin/tokervpn-speed-audit` — основной скрипт проверки;
- `docs/GITHUB.md` — как выложить в GitHub и запускать одной командой.

## Локальный запуск

```bash
chmod +x install.sh
sudo bash install.sh
```

Если хотите только повторную проверку без установки:

```bash
sudo tokervpn-speed-audit
```

Если нужно принудительно пересобрать локальный скрипт:

```bash
sudo bash install.sh --force-install
```

## Что ставится на сервер

- `speedtest`
- `jq`
- `curl`
- `gnupg`
- `ca-certificates`

`gnupg` и `ca-certificates` нужны только на этапе установки Speedtest.

## Куда ставится

- основной скрипт: `/opt/tokervpn-speed-audit/tokervpn-speed-audit`
- команда запуска: `/usr/local/bin/tokervpn-speed-audit`

## Примечания

- установщик рассчитан на Ubuntu с `apt`;
- если `apt` упирается в проблему с `packagekit.service`, установщик пробует ее обойти автоматически;
- если на сервере уже стоит Speedtest, повторной установки не будет.
