# speed-audit

Небольшой GitHub-ready набор для установки Ookla Speedtest и понятной проверки сервера на русском языке.

Главный сценарий запуска:

```bash
curl -fsSL https://raw.githubusercontent.com/MALYSHVIP/speed-audit/main/install.sh | sudo bash
```

После первого запуска установщик:

- ставит только нужные пакеты;
- устанавливает `speedtest`, если его еще нет;
- раскладывает локальную команду `speed-audit`;
- сразу показывает итоговый отчет по серверу;
- после отчета открывает русское меню быстрых действий по номеру.

При повторном запуске установщик ничего не переустанавливает и сразу переходит к проверке, если `speedtest`, `jq`, `curl` и локальный скрипт уже на месте.

## Что показывает отчет

- загрузку процессора и краткую оценку;
- сколько занято оперативной памяти и сколько доступно;
- сколько занято и сколько свободно на диске;
- оценку служебного мусора: кеш `apt`, временные файлы и журналы;
- ping, jitter, потери пакетов;
- скорость загрузки и отдачи;
- итоговую рекомендацию простыми русскими словами;
- меню действий: быстрая очистка, очистка кеша, очистка журналов, очистка временных файлов, повторный Speedtest и повторная полная проверка.

## Структура

- `install.sh` — установщик под запуск через `curl -fsSL ... | sudo bash`;
- `bin/speed-audit` — основной скрипт проверки;
- `docs/GITHUB.md` — как выложить в GitHub и запускать одной командой.

## Установка с GitHub

```bash
curl -fsSL https://raw.githubusercontent.com/MALYSHVIP/speed-audit/main/install.sh | sudo bash
```

## Локальный запуск из папки

```bash
chmod +x install.sh
sudo bash install.sh
```

## Повторная проверка без установки

Если скрипт уже установлен:

```bash
sudo speed-audit
```

После отчета откроется меню, где можно сразу:

- сделать безопасную быструю очистку;
- почистить только кеш `apt`;
- уменьшить старые журналы;
- удалить старые временные файлы;
- повторить `Speedtest`;
- повторить полную проверку.

## Принудительное обновление локального скрипта

Если нужно заново скачать актуальный скрипт проверки:

```bash
curl -fsSL https://raw.githubusercontent.com/MALYSHVIP/speed-audit/main/install.sh | sudo bash -s -- --force-install
```

## Что ставится на сервер

- `speedtest`
- `jq`
- `curl`
- `gnupg`
- `ca-certificates`

`gnupg` и `ca-certificates` нужны только на этапе установки Speedtest.

## Куда ставится

- основной скрипт: `/opt/speed-audit/speed-audit`
- команда запуска: `/usr/local/bin/speed-audit`

## Примечания

- установщик рассчитан на Ubuntu с `apt`;
- если `apt` упирается в проблему с `packagekit.service`, установщик пробует ее обойти автоматически;
- если на сервере уже стоит Speedtest, повторной установки не будет;
- `install.sh` подтягивает основной скрипт из `bin/speed-audit`, поэтому обновления лучше публиковать сразу и в `install.sh`, и в `bin/`.
